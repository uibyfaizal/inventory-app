# SiGudang | Inventory App 📦

A simple inventory management application built with Laravel.

## Features
- Product Management
- Category Management
- Stock Tracking
- Transaction History
- Export PDF
- Dashboard Statistics

## Tech Stack
- Laravel
- SQLite
- Blade
- TailwindCSS

## Status
This project is still under development, and more features will be added:
- Authentication System
- Minimum Stock Warning
- Global Transaction History
